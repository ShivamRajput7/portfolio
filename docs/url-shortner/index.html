# Sign Up Form

1. Type your name here

2. Type your email.

3. Type set a strong password

4. Click on Sign Up

5. Paste "your valid URL" into input

for example I pasted "https://github.com/ShivamRajput7" into input

6. Click on Generate URL button

7. You will get a short url

# URL Shortener

8. Click on Check Analytics

9. Type your registered email here

10. Type password

11. Click on Login

12. You can see your created link here
